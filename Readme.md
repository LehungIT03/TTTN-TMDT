# TTTN-ThuongMaiDienTu

This project is built using Node.js. Below are the steps to set up and run the project.

## Điều kiện cần thiết

- [Node.js](https://nodejs.org/) (phiên bản 14 hoặc cao hơn)
- [npm](https://www.npmjs.com/) (sử dụng npm)

## Cài đặt

1.1 Clone code:
git clone https://github.com/LehungIT03/TTTN-TMDT.git
mở file bằng Vusual Studio Code
1.2
cd server
cd thuongmaidientu

2. cài đặt thư viện:
   npm install

## Sử dụng

1. bắt đầu cơ bản:
   sử dụng  
   npm start
   [sử dụng npm start ở cả 2 file server và thuongmaidientu]
2. Open your browser and navigate to `http://localhost:3000`.

## các lệnh

- `npm start`: khởi chạy dự án.
- `npm run build`: khởi chạy xây dựng sản phẩm
